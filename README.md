# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3192 |
| 应用 | http://localhost:8192 |
| PostgreSQL | localhost:54392 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| taster | tea123456 | 可审评 |
| observer | look123456 | 只看 |

## 启动

```bash
cd projects/13-tea-blend-cupping
docker compose up --build
```

## 轮值名单

顶栏「轮值名单」进入专页，今日生效簿、明日预排簿、排班履历同页。

- 不在今日生效簿内的审评员会话，交评一律拒绝（服务端 403）。
- 审评员可在两簿批量粘贴人名（空格/逗号/换行分隔），重名跳过并提示；可移出。
- 跨自然日自动把明日预排提升为今日生效并清空明日簿，写一条日切履历；专页也提供「执行日切」按钮便于演练。
- 履历记录谁在何时把谁加入/移出哪本簿，以及日切。
- observer 可看两簿与履历，排班操作返回 403。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分（如批次 春芽），新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单，也没有排班表单。
4. 把 taster 移出今日生效簿后再交评，被拒绝并提示；加回今日簿后提交「春芽」成功。
5. 在明日预排簿写入另一个人名（如 tester2），履历立即可见；执行日切后，该人名出现在今日生效簿，明日预排清空，履历多一条日切。
6. 一次粘贴多个人名批量加入今日簿，与簿内重名者被跳过并逐条提示。
