# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 轮值名单（交评门控）

只有**今日生效簿**内的审评员会话可以交评；不在簿内一律 403 拒绝。名单分两簿，顶栏「轮值名单」进入专页，两簿与排班履历同页：

- **今日生效簿**：当日可交评班底。支持一次粘贴多个人名批量写入（换行、空格、逗号、顿号、分号皆可分隔），同簿重名与粘贴内重复都会跳过并在页面提示。
- **明日预排簿**：次日班底。跨自然日首次访问系统时自动**日切**——明日预排提升为新的今日生效，明日预排清空，并写一条「跨日日切」履历。审评员也可在专页手动「执行日切」（用于当日预演，写「手动日切」履历，不影响次日正常跨日）。
- **排班履历**：记录谁在何时把谁加入/移出哪一簿，以及每次日切提升了哪些人。
- 审评员（writer）可排班；观察员（reader）能看两簿与履历，页面无排班控件，直接 POST 写接口返回 403。

## 启动

```bash
cd projects/13-tea-blend-cupping
docker compose up --build
```

初始库内今日生效簿含 `taster`，开箱即可交评。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单；进入轮值名单能看两簿与履历，没有任何排班/日切按钮，直接调用写接口返回 403。
4. 顶栏「轮值名单」进专页，今日生效簿、明日预排簿、排班履历同页可见。
5. 在专页把当前审评员 taster 移出今日生效簿，回到审评台交「春芽」应失败（403，提示不在今日生效簿）；把 taster 加回今日生效簿后再交「春芽」应成功。
6. 在明日预排簿写入另一个人名（如 `轮值乙`），履历中可见「taster 加入 轮值乙 到明日预排簿」；点「执行日切」（或模拟跨自然日）后，该人名出现在今日生效簿，明日预排簿清空，履历多出一条日切记录。
7. 一次粘贴 `阿甲\n阿乙,阿丙、阿乙` 到今日簿，三人写入，重复的阿乙被跳过并在提示中列出。
